## 1. 要点

1. 【事実】「自動化」そのものを禁じているサービスはほぼない。ただし、**人が確認しない大量生成**は各社が2025〜2026年に相次いで締め付けている：YouTube は 2025-07-15 に「繰り返しの多いコンテンツ」を「量産型のコンテンツ」に改名して明確化、BOOTH は 2025-07-18 に AI 生成作品への対応を強化、Zenn は 2026-03-10 に「人が主体（公開前に正確性を検証）」の方針と投稿数の上限を表明、Google 検索は「大量生成されたコンテンツの不正使用」をスパムに指定。〔R8-20, R8-39, R8-28, R8-26｜2026-09-29〕
2. 【事実】18歳未満の扱いは3種類に分かれる。**保護者の同意で本人が利用できる**のは note（有料記事・メンバーシップは保護者が同意フォームを提出）、BOOTH、LINE Creators Market、GitHub Sponsors（13〜17歳は保護者の本人確認が必要）。**保護者名義にする**必要があるのは YouTube／Google AdSense（保護者の AdSense に収益が入る）と KDP（保護者が出版者になる）。**18歳まで使えない**のは X の収益化（18歳以上）、A8.net（同意があっても不可）、Amazonアソシエイト（未成年ではないことを表明保証させる規約）。〔R8-01〜03, R8-34, R8-42, R8-49, R8-22〜23, R8-40, R8-15, R8-48, R8-45｜2026-09-29〕
3. 【事実】X API は2026年時点で**従量課金（クレジット制）**。投稿1件 $0.015、**URL付き投稿は1件 $0.200**。公式ドキュメントに無料枠の記載はない。X のクリエイター収益分配（Creator Revenue Sharing）は**2026年9月に終了し、Original Content Rewards に置き換わった**（Premium加入、認証ユーザーからのインプレッション50万／90日、認証フォロワー500、18歳以上）。〔R8-11, R8-14, R8-15, R8-16｜2026-09-29〕
4. 【事実】**note には公式の公開APIがない**（今後も未定）。一方、Zenn は GitHub へ push すると自動で公開される公式連携があり、Qiita は API v2 で記事を投稿できる。〔R8-05, R8-30, R8-33｜2026-09-29〕
5. 【事実】ステマ規制（2023-10-01施行）で規制されるのは**広告主**。ただし消費者庁のQ&Aでは、「PR」表示をリプライ欄に書くだけ、あるいは動画の冒頭だけに入れるのは「明瞭とはいえない場合が多い」とされている。〔R8-55, R8-56｜2026-09-29〕
6. 【事実】AI生成物が著作権を侵害するかどうかは、通常の著作物と同じく**類似性と依拠性**で判断される。既存作品の題名やキャラクター名をプロンプトに入れると、依拠性が推認されやすい（文化庁の2024年の「考え方」による）。〔R8-57, R8-58｜2026-09-29〕
7. 【事実】**ITパスポートの本番（CBT）で出た問題は、SNSへの投稿も含めて開示してはならない**（受験時に同意したことになり、違反すると損害賠償の対象）。IPA が公表している過去問は、出典を明記すれば許諾も使用料も不要。共通テストの過去問を二次利用する（Web上の問題集を含む）には、大学入試センターへの**事前申請**が必要。〔R8-63, R8-62, R8-64｜2026-09-29〕

## 4. 著作権・ステマ規制・過去問利用の注意点

### 4-1. 生成AIと著作権（文化庁「AIと著作権に関する考え方について」2024-03-15）
- 【事実】まとめたのは文化審議会著作権分科会の法制度小委員会で、2024-03-15 に公表された。概要版（2024年4月）と、利用者向けの「チェックリスト＆ガイダンス」（2024-07-31）もある。〔R8-57｜2026-09-29〕
- 【事実】「開発・学習段階」と「生成・利用段階」を分けて考える。生成・利用段階では、**通常の著作権侵害と同じく「類似性」と「依拠性」**で判断する。AI の利用者が既存の著作物を知ったうえで、生成AIで似たものを作れば依拠性が認められる。既存の著作物そのものや、**題名・キャラクター名などを指示として入力**すると、既存作品を知っていたことの間接的な証拠になり、依拠性が認められやすい。〔R8-58｜2026-09-29（概要PDFの取得は確認。内容は bunka.go.jp の検索抜粋で確認）〕
- 【事実】AI生成物が著作物になるかどうかは、個別の事情で判断する。単なる労力ではない「創作的寄与」がどれだけ積み重なっているかが基準で、長いプロンプトでもアイデアを示すだけなら創作的寄与にはならない。〔R8-58｜2026-09-29（検索抜粋）〕
- 【推定】AI にほぼすべてを作らせた記事や画像は、本人の著作物として保護されない可能性がある。有料で販売しても、他人が転載したときに権利を主張しにくい。

### 4-2. ニュース記事の要約投稿
- 【事実】著作権法10条2項：「事実の伝達にすぎない雑報及び時事の報道は、前項第一号に掲げる著作物に該当しない。」〔R8-60｜2026-09-29〕
- 【事実】著作権法32条1項：引用は「公正な慣行に合致するもの」で、かつ「引用の目的上正当な範囲内」で行わなければならない。〔R8-60｜2026-09-29〕
- 【推定】保護されないのは「事実そのもの」だけ。記事の文章表現や構成を下敷きにした要約は、翻案として侵害になりうる。AI に記事本文を入力して要約させれば、依拠性は明らか。
- 【参考】日本新聞協会は、報道コンテンツを生成AIが学習・利用する場合は権利者の許諾を得るよう求める声明を出している（2025-06-04）。〔R8-65｜2026-09-29〕
- 【意見】「ニュースを自動要約してX・noteに投稿する」形は避ける。一次情報（官公庁や自治体の発表）へのリンクと、自分のコメント・解説を主にし、引用するなら主と従を明確にして出所を明示する。

### 4-3. ステルスマーケティング規制（景品表示法、2023-10-01施行）
- 【事実】「広告であるにもかかわらず、広告であることを隠す」ことが規制の対象。規制されるのは**広告主（商品・サービスを供給する事業者）**で、依頼を受けたインフルエンサーなどの第三者は規制の対象外。〔R8-55｜2026-09-29〕
- 【事実】「広告」であることを明瞭に示す方法として「広告」「宣伝」「プロモーション」「PR」の表示や、「A社から商品の提供を受けて投稿している」といった文章が挙げられている。**アフィリエイトサイトの冒頭に一文あるだけでは、文字の大きさや色によっては不十分**。SNSで本文ではなくツリー（リプライ）に「広告」と書くのは、**明瞭とはいえない場合が多い**。動画は冒頭だけでは見逃されるおそれがあり、**画面に常に表示するのが望ましい**。〔R8-56｜2026-09-29〕
- 【事実】note の規約は景品表示法に違反するもの（そのおそれがあるものを含む）の掲載を禁止し、Qiita の規約はアフィリエイトを目的とした投稿を禁止している。〔R8-01, R8-31｜2026-09-29〕
- 【意見】自動投稿の仕組みにアフィリエイトリンクを含める場合は、**本文の先頭に「PR」「広告」を必ず入れるテンプレート**にする。X ではリンク付き投稿のAPI料金も $0.200 と高いので、リンクを大量に自動投稿する設計はコスト面でも規約面でも割に合わない。〔R8-11｜2026-09-29〕

### 4-4. 過去問の利用
- **IPA（ITパスポートを含む情報処理技術者試験）**
  - 【事実】公表されている過去問は「法令に特別の定めがある場合を除き許諾や使用料は必要ありません」。教育目的など、試験制度の意義に反しない限り、問題集やテキストに使ってよい。出典は「出典：平成31年度 春期 基本情報技術者試験 午前 問1」のように年度・期・試験区分・時間区分・問番号まで書き、**一部を改変した場合はその旨も明記**する。著作権は放棄されていない。〔R8-62｜2026-09-29〕
  - 【事実】**ITパスポートの試験問題は非公開**。受験者は、試験問題の全部または一部（出題内容を示唆する表現を含む）を第三者に開示しないことに同意して受験する。SNS への投稿やネット掲示板への書き込みも開示（漏洩）とみなされる場合があり、損害賠償請求などの措置がとられる。〔R8-63｜2026-09-29（検索抜粋）〕
  - 【意見】2026年9月末に受験するので、「今日出た問題」「こんな問題が出た」といった投稿は、**記事や自動投稿の素材にしない**。使うのは IPA の公開問題（【参考】検索抜粋では毎年4月ごろに100問を公開）に限り、出典を明記する。
- **大学入試センター（共通テスト「情報I」など）**
  - 【事実】試験問題の著作権はセンターにある。複写、他者への配布、インターネット上を含む問題集の作成といった**二次利用には、事前に「試験問題利用申請」が必要**（承認は通常8営業日以内、利用できるのは試験実施日の翌日以降）。第三者が権利を持つ部分は、利用者が自分でその権利者から許諾を得る。〔R8-64｜2026-09-29〕
  - 【意見】「情報Iの過去問解説」を note の有料記事にしたり、PWA の問題アプリにしたりする場合は、公開前に申請が必要。自分の学習のために解くだけなら不要。

### 4-5. 未成年の契約（民法）
- 【事実】民法5条：未成年者が法律行為をするには法定代理人の同意が必要で、同意のない行為は取り消すことができる。6条：営業を許された未成年者は、その営業に関しては成年者と同じ行為能力を持つ。〔R8-61｜2026-09-29〕
- 【推定】規約に「保護者同意」と書いていないサービス（Zenn・Qiita・楽天など）でも、販売や報酬の受け取りを伴う契約は、民法上は保護者の同意が前提になる。

## 5. 依頼者への実務上の結論（10項目）

### A. 本人名義でできること（収益を伴わない、または規約上本人で可）
1. 【事実＋意見】**Zenn・Qiita・note（無料記事）で技術記事を出す**（Claude Code・PWA・Workers で API キーを隠す構成など）。自動化は「AIが下書きを作り、本人が検証し、GitHub 連携（Zenn）や API（Qiita）で公開する」まで。検証しない自動投稿は、Zenn では規約違反、Qiita ではガイドライン違反になる。〔R8-27〜R8-33｜2026-09-29〕
2. 【事実＋意見】**X での発信は本人アカウントで可能**（13歳以上）。ボットとして運用するなら「automated」ラベルを付けて管理者を表示し、重複投稿やキーワードだけを根拠にした自動リプライはしない。AIによる自動返信は事前承認が必要なので**やらない**。〔R8-08〜R8-10, R8-17｜2026-09-29〕
3. 【事実＋意見】**ITパスポートの公開過去問を解説する**（出典を明記し、改変したらその旨も書く）。本番で見た問題は一切書かない。地元（みなかみ・沼田）の情報発信で自治体や観光協会の発表を使うときも、要約の丸写しは避け、リンクと自分の取材・写真を中心にする。〔R8-62, R8-63, R8-60｜2026-09-29〕

### B. 保護者の同意・名義が必要なこと
4. 【事実】**note の有料記事・メンバーシップ**：保護者本人が同意申請フォームに入力し、本人確認書類（マイナンバーの記載なし）を提出する。手数料はカード決済で約14.5%、振込は1回270円。「必ず儲かる」系の表現や、売上を見せて購入をあおる書き方は禁止。〔R8-01〜R8-04｜2026-09-29〕
5. 【事実】**BOOTH（デジタル商品）・LINEスタンプ**：親権者（法定代理人）の同意があれば本人が利用できる。手数料は BOOTH が5.6%＋45円、LINE が（売上－ストア手数料）×50%。AI生成素材を量産して出品すると、BOOTH では検索から外される。LINE では「AI生成」と表示される。〔R8-34〜R8-39, R8-42｜2026-09-29〕
6. 【事実】**YouTube と自分のサイトの AdSense は、保護者の AdSense アカウントに収益が入る**。YPP のしきい値は最低でも登録者500人。AIで量産した動画は「量産型のコンテンツ」として収益化の対象外で、写実的なAIは開示が必須。〔R8-18〜R8-24｜2026-09-29〕
7. 【事実】**KDP は保護者が出版者として KDP アカウントを作る**。AI生成のテキスト・画像・翻訳は申告が必須（表紙画像を含む）。〔R8-40, R8-41｜2026-09-29〕
8. 【事実＋推定】**X API（従量課金のクレジット購入）、Chrome Web Store の登録料、有料 API の契約は、支払い手段も契約者も保護者**になる（前提仮定A12と整合）。X API の目安は、リンクなし投稿を1日10件なら月300件×$0.015＝約$4.5、リンク付きなら月300件×$0.200＝約$60【推定：公式単価からの計算】。〔R8-11, R8-43, R8-44｜2026-09-29〕
9. 【事実】**GitHub Sponsors は17歳でも可能**だが、Stripe が保護者の確認情報を集められることが条件（個人からのスポンサー料は手数料0%）。**もしもアフィリエイト**は年齢制限がなく、保護者の許可を得てからの開始が推奨されている。どちらも「広告」「PR」表示のルールは同じく守る。楽天アフィリエイトで未成年が使えるかは**要確認**。〔R8-47, R8-49, R8-50, R8-46｜2026-09-29〕

### C. 18歳以降に使えるもの（2027年4月〜2028年4月1日の誕生日以降：仮定A1）
10. 【事実】**X の収益化（Original Content Rewards：18歳以上・Premium加入・インプレッション50万／90日・認証フォロワー500）、A8.net（18歳未満は同意があっても不可）、Amazonアソシエイト（未成年ではないことを表明保証する規約）、本人名義の AdSense・KDP**。18歳までは、上のA・Bで**実績（記事・フォロワー・作品）を積む期間**と考えるのが、規約上もっとも無理がない【意見】。〔R8-14, R8-15, R8-48, R8-45, R8-23, R8-40｜2026-09-29〕
