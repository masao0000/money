## 2. 自動化の現実 / How Far Automation Goes
- X API は無料枠なし。投稿1件$0.015、**URL付きは$0.20（約30円）**（R10-11）
- note は**公式APIなし**。自動投稿は非公式手段＝停止リスク（R10-14, R8-05）
- YouTube は未監査アプリからの自動アップロードが**非公開に固定**（R10-18）
- Zenn は「機械で自動生成した文章」をスパムと明記。**公開前の人の検証が必須**（R8-27/28）
- Bluesky・Threads は無料APIで自動投稿できる（R10-23〜26）
- 生成AIの費用は小さい：Sonnet 5.5 で1本約3.6円（R10 §4）。API契約は**保護者名義**（Anthropic消費者規約・Gemini APIは18歳以上：R10-36/40）
- 結論【意見】：**「下書きと予約は自動、公開前に本人が1本1〜3分確認」＝半自動が規約上の上限**。運用は週20〜40分（R10 §8）

## 4. 法律・税 / Law and Tax
- 未成年の契約は保護者の同意（民法5条）。取消権あり（R8-61）
- 共通テストの過去問の二次利用は**大学入試センターへの事前申請**が必要（R8-64）。IPAの公開過去問は出典明記で許諾不要（R8-62）。**ITパスの本番の問題は開示禁止**（R8-63）
- 税：基礎控除58万円・扶養親族の所得要件58万円（令和7年度改正）。住民税は1月1日時点で18歳未満なら合計所得135万円以下で非課税（R9-18/19）→ 1年目の見込み額では**税の負担はほぼ生じない**【推定】
- 時間効率の基準：群馬県最低賃金 **1,120円**（2026-10-03〜）（R9-17）
