# R10 自動制作・自動配信の仕組みのコストと実現性

- 調査日：2026-09-29（本文中の出典は、すべてこの日に確認）
- 為替：1ドル＝145〜155円で計算し、円は幅で示す（例：$0.024 → 3.48〜3.72円）
- 表記：【事実】＝公式ページで確認した内容／【推定】＝事実からの計算や推測／【意見】＝調査者の判断。出典IDは §9 の一覧に対応
- 「要確認」＝公式ページを開けなかった（403など）か、ページに記載がなかった項目。URLは実際に開けたものだけを載せた
- 前提：依頼者は18歳未満。契約・課金・API登録は**保護者の同意と保護者名義（または保護者の管理）が前提**（`00_assumptions.md` A12）

## 1. 要点

1. 【事実】定期実行は無料枠で足りる。GitHub Actions は公開リポジトリなら無料、非公開でも月2,000分。Cloudflare Workers の無料プランは1日10万リクエスト、Cron Trigger（定期実行の設定）はアカウントあたり5個。ただし公開リポジトリの定期実行は**60日間活動がないと自動で止まり**、毎時0分前後は遅れたり、実行されないこともある（R10-01〜03, 05〜07）。
2. 【事実】X API は2026-02-06に従量課金へ移行し、**無料枠はない**。投稿1件$0.015（約2.2〜2.3円）、**URL付きの投稿は$0.20（約29〜31円）**（R10-11, 12）。【意見】noteへのリンクを毎回付けて自動投稿すると割高になる。
3. 【事実】noteには公式APIがなく、公開予定も「未定」（R10-14）。【意見】noteは「下書きまで自動で作り、投稿は手で行う（1本2〜3分）」形が安全。
4. 【事実】YouTube API は、監査を受けていないプロジェクトからアップロードした動画が**非公開に固定**される。OAuth の公開ステータスが「テスト」のままだと、リフレッシュトークンが**7日で失効**する（R10-18, 20）。【推定】個人が「完全自動で公開」まで回すのは難しい。
5. 【事実→推定】1本（入力2,000・出力2,000トークン）の生成コストは、Claude Haiku 4.5 が約1.7〜1.9円、Sonnet 5.5 が約3.5〜3.7円、Gemini 2.5 Flash-Lite が約0.15円。【事実】Anthropic の消費者向け規約と Gemini API 規約は**18歳以上**が条件（R10-35, 36, 39, 40）。
6. 【事実】GTX 1080（Pascal世代）は、PyTorch 2.8以降の CUDA 12.8/12.9 版では非対応。NVIDIA ドライバも580系が最後（R10-49, 50）。【推定】Whisper（turbo/medium）、VOICEVOX、8B級LLM（4bit量子化）、SD1.5/SDXL（省メモリ設定）は動くが、どれも遅い。
7. 【意見】推奨は「月500円構成」。Workers の無料枠で定期実行し、Claude API で下書きを作る。Bluesky/Threads は自動投稿、X はURLなしの投稿を少しだけ、note と YouTube は半自動にする。週の保守は20〜40分が目安（§8）。

## 4. 生成AIの1本あたりコストと年齢要件

### 4-1. 計算式
- **1本のコスト（ドル）＝（入力トークン数×入力単価＋出力トークン数×出力単価）÷1,000,000**
- 前提：入力2,000、出力2,000トークン。円は×145〜155円。
- 例（Claude Sonnet 5.5）：(2,000×$2＋2,000×$10)÷1,000,000＝**$0.024** → 3.48〜3.72円

## 5. ローカルAI（GTX 1080・8GB）でできること・できないこと

### 5-1. Pascal世代（GTX 1080）の注意点
- 【事実】PyTorch 2.8から、**CUDA 12.8/12.9版のバイナリで Maxwell と Pascal の対応が外された**（2025-07-14の告知、R10-49）。【推定】最新の PyTorch をそのまま入れると GPU を認識しない。CUDA 12.6版など古いビルドを選ぶ必要があり、将来この版の対応も終わる可能性がある（要確認）。
- 【事実】NVIDIA のドライバは **580系が Maxwell・Pascal・Volta を対応する最後の系列**（R10-50、参考記事で確認）。NVIDIA の公式サポート計画（2028年10月までセキュリティ更新）は、ページが403で開けなかった＝**要確認**。
- 【事実】Ollama は計算能力5.0以上に対応し、GTX 1080（6.1）も一覧にある。ただし5.0〜6.2の世代は**ドライバ570以上が必要**（R10-51）。【推定】580系で条件を満たせる。
- 【事実】ComfyUI Wiki（参考）には「10シリーズ（Pascal）以前はFP32のみ・非推奨」とあり、FP16のハードウェアによる高速化がない（R10-59）。【推定】画像生成は新しい世代のGPUより数倍遅い。

### 6-3. 自動生成した動画の収益化リスク
- 【事実】YouTube の収益化ポリシーでは、**繰り返しの多い量産型のコンテンツ**は収益化の対象外。例として「最小限の語りしかない画像スライドショー、テンプレート化した筋書き、スクロールする文字」「一般的でありきたりなテンプレートで作ったAI生成コンテンツ」が挙げられている（R10-22）。
- 【意見】タイマー動画やスライド動画を**テンプレートのまま量産すると収益化の審査に通らない**おそれが高い。1本ごとに本人の解説・問題の選び方・声などの付加価値を入れる。YouTube は「集客用（PWAや問題集への導線）」と割り切るのが安全。

## 8. 推奨構成案（3つ）

### 8-0. パイプラインが止まる典型的な原因と、保守時間の目安

| 原因 | 具体例（出典） | 頻度・対策 |
|---|---|---|
| 定期実行の停止・遅延 | GitHub の公開リポジトリは60日間活動がないと停止。毎時0分前後は遅延や欠落（R10-02, 03）。Workers の Cron は UTC で、時刻どおりの保証はない（R10-07） | 【推定】数か月に1回。実行時刻を毎時0分からずらす。成功したらログを残し、失敗したら自分に通知する |
| トークンの失効 | Google OAuth の「テスト」状態は7日で失効（R10-20）。Threads と Instagram の長期トークンは60日（R10-26, 28） | 【推定】YouTube を自動化すると**毎週**、Meta系は**2か月ごと**。自動更新ジョブを入れ、失敗したら通知する |
| 料金・仕様の変更 | X：2026-02に従量課金へ移行、2026-04に改定（R10-12）。Gemini 3.8 Flash は2027-01に値上げ（R10-39）。Claude の旧モデルは提供終了（R10-35）。LINE は2026-10に料金改定（R10-34） | 【推定】四半期に1〜2件。モデル名や単価を設定ファイルに分けておき、月1回公式ページを見る |
| APIの提供自体がない・規約変更 | note は公式APIなし（R10-14）。YouTube は未監査だと非公開に固定（R10-18） | 手動の工程を最初から組み込む（下書きは自動、公開は手動） |
| レート制限・残高切れ | Workers Free は10ms CPU・サブリクエスト50回（R10-06）。X の前払いクレジットの残高切れ（R10-11） | 【推定】月1回程度。1回の実行で処理する件数を小さく分ける。残高の自動チャージと上限額を設定する |
| ローカル環境の破損 | PyTorch 2.8以降の CUDA 12.8版は Pascal 非対応（R10-49）。ドライバは580系が最後（R10-50） | 【推定】更新のたびに起こりうる。動く版を固定し、更新を止める |
| 規約違反による停止 | Vercel Hobby の商用利用（R10-10）、X の重複投稿（R10-13、要確認）、note のスパム判定（R10-15） | 【意見】同じ文面を繰り返さない。投稿の頻度は人が投稿する程度に抑える |

- 【推定】週あたりの保守時間：**0円構成は30〜60分**（手動投稿を含む）、**500円構成は20〜40分**、**1,500円構成は40〜90分**。これとは別に、**障害対応に四半期あたり2〜4時間**。完全に手放しでは回らず、「毎週15分の点検」と「月1回の規約・料金の確認」は残る。
- 【意見】個人ブログで「完全放置で稼げる」とされる構成の多くは、非公式APIやブラウザの自動操作に頼っていて、止まりやすく規約上のリスクも大きい。この調査では勧めない。

### 8-1. 0円構成（初期0円・月0円＋電気代）

- **配信**：
  - Cloudflare Pages（問題集PWA＋RSS、静的アセットは無制限）

  - Threads（自分をテスターにしたアプリ）への自動投稿
  - LINE 無料プラン（週1回、46人まで。応答メッセージは無制限）
- **手動**：X（下書きをコピーして投稿）、note（Markdown の下書きを貼る）、YouTube（Studio でアップロード・予約公開）
