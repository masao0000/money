# 07 運用のチェックリスト / Operations Checklist

---

## 1. 完成の条件（3行。これ以外は「次の版」リストへ）
1. 自作の問題30問が、AIの答え・モデル名・日付・正誤・解説つきでそろっている
2. 承認した問題だけが、毎朝7時に Bluesky・Threads に自動で出る（X は手動でもよい）
3. 「AIのまちがい方10の型・30問」のPDFが、無料サンプルつきでBOOTHにある

## 2. 「次の版」リスト（今は作らない）
- 承認PWA（60問たまってから）
- 他の教科・ITパスへの拡大
- 動画・音声
- 会員登録・コメント欄・ランキング

## 3. 承認前の4点チェック（1問ごと。1つでも×なら公開しない）
- [ ] **出典**：教科書・公的な資料のどこで確かめたか書いた
- [ ] **数字**：計算・単位・桁を自分で解き直した
- [ ] **禁止の素材でない**：共通テストの過去問・ITパスの本番の問題・定期考査・市販の問題集を使っていない
- [ ] **表示**：AIのモデル名と日付を書いた。個人情報（本名・学校名・地名）が入っていない

|---|---|---|---|---|---|---|---|

- 評定が下がった月の翌月は止める。

## 5. 撤退基準（数値と期限）
| 期限 | 条件 | 当たったら |
|---|---|---|
| 2026/10/20 | 自作30問でAIのまちがいが2問以下 | テーマを「AIの正しい使い方で解く」に変える（**唯一のテーマ変更の条件**） |
| 2026/12/15 | SNSのフォロワー合計が30未満 | SNSの投稿をやめ、サイトとPDFだけにする |

| いつでも | 評定が下がる | 翌月は止める |

## 6. 凍結カレンダー（保護者・担任と共有）
- 定期考査の2週間前〜最終日：すべて止める
- Apple Lounge 実証の前後1週間：新しいことはしない
- 2026/11/15〜12/15：新しいことはしない（予約投稿と週1回の承認だけ）
- 2027/1/4〜英検の一次：運用だけ
- 2027/6/1〜1学期の期末考査の終わり：すべて止める
- 2027/8/1〜推薦の発表：自動投稿も止める

## 7. すべてを止める手順（トラブルのとき）
1. GitHub Actions（または Workers）の定期実行を無効にする
2. Bluesky・Threads・X に「しばらく休みます」と1回投稿する
3. BOOTHの商品を非公開にする
4. 保護者に連絡する
