# 08 AIに解かせるときの記録の型と、まちがい方の分類 / Log Format and Error Types

---

## 1. AIへの頼み方（毎回同じ文にする。答えを比べるため）
```
次の問題に答えてください。選択肢がある場合は記号で答え、理由を3文以内で書いてください。

問題：
［自作の問題文］
```
- 同じ問題を、同じ日に、2〜3種類のAIに同じ文で聞く。
- AIは保護者名義のAPI（Claude など）か、保護者の管理のもとで使う（消費者向けのClaudeは18歳以上：R10-36）。
- AIに**問題を作らせない**。AIの役目は「解く」だけ。

## 2. 記録の表（スプレッドシート1行＝1問×1つのAI）
| 列 | 例 |
|---|---|
| 問題ID | Q-2026-10-001 |
| 分野 | 情報の表現（2進数） |
| 問題文 | （自作） |
| 正解 | （自分で解いた答え） |
| 根拠 | 教科書○ページ／公的な資料のURL |
| AIのモデル名 | （例：claude-haiku-4-5） |
| 聞いた日 | 2026-10-05 |
| AIの答え | （そのまま貼る） |
| 正誤 | ○ / × |
| まちがい方の型 | （下の表から選ぶ） |
| 解説 | （自分の言葉で） |
| 承認 | 未／済（4点チェックを通したら「済」） |
| 公開日 | （自動で入る） |

## 3. まちがい方の型（最初の候補。実験1の結果で直す）
| # | 型 | 例 |
|---|---|---|
| 1 | 桁・単位のずれ | ビットとバイト、KBとKiBの取り違え |
| 2 | 条件の読み落とし | 「〜でないもの」を選ぶ問題で逆を選ぶ |
| 3 | 手順の添字のずれ | 配列の番号が0から始まるか1から始まるか |
| 4 | 例外の取り違え | 著作権の例外（引用など）の条件 |
| 5 | もっともらしい作り話 | 存在しない用語・規格を答える |
| 6 | 古い情報 | 制度・規格の変更前の内容で答える |
| 7 | 計算の途中の誤り | 2進数・16進数の変換、確率 |
| 8 | 図・表の読み違い | 問題文の表の行と列を取り違える |
| 9 | 言いすぎ | 「必ず」「絶対」と言い切る |
| 10 | 問いのずれ | 聞かれていないことに答える |
