## 「AIがまちがえた情報I」をやらせてください

### 1. 何をするか
- 情報Iの教科書で自分が問題を作り、いくつかのAIに解かせる。AIがまちがえた問題を、正しい解説と一緒に、毎朝SNS（Bluesky・Threads・X）と自分のサイトに出す。
- 3か月ごとに、問題をまとめたPDF（500円）をBOOTHで売る。
- **問題を作って確かめる作業が、そのまま自分の共通テスト（情報I）の勉強になる。**

### 2. 名義と契約
| サービス | 何に使う | 年齢の条件 | 名義 |
|---|---|---|---|
| BOOTH | PDFの販売 | 18歳未満は親権者の同意が必要 | 本人（同意書あり） |
| Claude API | AIに問題を解かせる | 事業者向け契約（消費者向けは18歳以上） | **保護者** |
| X API | 毎朝の自動投稿（URLなし1件約2円） | 有料のクレジット | **保護者** |
| Bluesky・Threads | 毎朝の自動投稿 | 13歳以上 | 本人（ペンネーム） |
| Cloudflare Pages | 自分のサイト | — | 本人 |

### 3. お金
- 初期費用：0〜3,000円（X と Claude のクレジット）
- 月の上限：**500円**。自動チャージは切る
- 入金口座：（保護者と決める）
- 税金：収入は「雑所得」。1年で58万円以下なら親の扶養から外れない。1月1日に18歳未満なら、住民税も合計所得135万円以下で非課税（国税庁・自治体の説明）

### 4. ネットに出す範囲
- **ペンネームで運用**。本名・学校名・顔・制服・自宅の近くの写真は出さない
- BOOTHの販売者の表示で住所・電話番号が出ない設定を確認してから販売する

### 5. トラブルのとき
- 問題の誤りの報告が来たら：48時間以内に訂正し、訂正したことを投稿する。2件以上たまったら販売を止める
- 炎上・苦情：すべての自動投稿を止める（止める手順を紙に書いて渡す）

### 6. 時間と勉強
- **週5時間まで、平日は1日45分まで**
- 定期考査の2週間前〜最終日、11/15〜12/15（GIAと期末）、2027年6月〜期末、2027年8月〜推薦の発表は止める
- 毎週、使った時間・売上・費用を記録し、**月1回見せる**。評定が下がったら翌月は止める
