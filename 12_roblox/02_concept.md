# 02 企画書：題材を1つに絞る / One-Page Game Plan

作成：2026-09-30 ／ 根拠：`01_analysis.md`
*This file scores five game ideas and picks one.*

## 1. 結論 / Conclusion
**「かかしの夜（Kakashi Night）」**：収穫祭の夜のりんご園で、**見ている間は止まり、目を離すと動くかかし**（＝だるまさんがころんだ）から逃げながら、金のりんごを5つ集めて門から出る、**10分で1回が終わる和風ライトホラー**。
*"Kakashi Night": in an apple orchard at night, collect five golden apples and escape from scarecrows that move only when you look away.*

- 選んだ理由：7つの基準の合計が最高（31/35点、§2）。「怖いけど少し笑える」（ヒット作の共通点）、日本らしい舞台（海外で売れる）、**廃旅館（ペタペタサマ）と重ならない**、1つのマップと単純なルールで作れる。
- 【意見】題材はあくまで提案。最後は本人が決める。

## 3. ゲームの中身（10分で1回）/ The 10-Minute Loop

| 時間 | 流れ |
|---|---|
| 0:00〜1:00 | ロビー（1〜6人）。提灯がともる収穫祭の入口 |
| 1:00 | 開始。りんご園に入る。**金のりんご5つ**が、12か所のうちランダムな5か所にある（有料ではない、公平なランダム） |
| 1:00〜9:00 | 探す。**かかしは、だれかが見ている間は止まり、全員が目を離すと近づく**。りんごを1つ取るごとに、かかしが1体増える |
| 2分ごと | **お寺の鐘が鳴る→提灯が10秒消える**（全員が見えなくなる＝一番の見せ場。配信で盛り上がる場面） |
| 9:00〜11:00 | 5つを収穫小屋に入れると門が開く。門まで走る |
| 終わり | タイムと称号（バッジ）。最速タイムのランキング |

- つかまったら：見物（かかしの目線で見られる。**少し笑える場面**）か、復活（有料の小さなアイテム）。
- 繰り返す理由：りんごの場所が毎回変わる、「雪の夜」モード（難しい）、称号集め、最速タイム。
- 中身の成熟度：**軽いホラー（Mild）**。流血なし。→ 審査を通れば5〜8歳のKidsにも表示できる範囲。

## 4. お金の入れ方（ガチャなし）/ Monetization (No Lucky Draws)
| 種類 | 例 | 価格（Robux） | 作り手の取り分 |
|---|---|---|---|
| ゲームパス（買い切り） | 強い懐中電灯（見える範囲が広い） | 99 | 70% |
| ゲームパス | 法被（はっぴ）の見た目 | 149 | 70% |
| ゲームパス | 提灯のペット（見た目だけ） | 199 | 70% |
| 開発者アイテム（何度も買える） | その場で復活 | 25 | 70% |
| 自動の報酬 | Creator Rewards（10分以上遊んだ対象者1人につき5 Robux） | — | — |
- 強すぎる有利（お金で勝てる）は入れない（口コミが悪くなる【推定】）。**中身の分からない有料のくじは入れない**（Robloxは確率の表示を求めている。日本の景品表示法の「コンプガチャ」禁止にも注意）。

## 5. 広がり方 / How It Spreads
- 配信者が叫ぶ・笑う場面を作る（鐘→暗闇、かかしが真後ろにいる）。【事実】「顔から逃げるゲーム」は海外のYouTuberの紹介で広がった（`01_analysis.md`）。
- 文字は最小限にして、Robloxの自動翻訳に任せる（日本発のゲームは収益の57%が海外から）。
- アイコン・サムネは「提灯の光に浮かぶ、かかしの顔」1枚で勝負する。
